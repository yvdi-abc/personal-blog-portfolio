## 欢迎 🎉

欢迎来到我的个人博客！这是一个基于 **Next.js 15** + **React 19** + **TypeScript** 构建的现代化博客系统。

### 主要特性

- ✨ **毛玻璃视觉效果** - 华丽的 UI 设计
- 🎨 **自定义背景** - 支持图片轮换和渐变模式
- 🌙 **深色模式** - 完美的夜间阅读体验
- 📝 **Markdown 支持** - 完整的 Markdown 语法支持
- 💻 **代码高亮** - 多语言语法高亮
- 🔍 **全文搜索** - 快速查找文章内容

### 代码示例

这是一段 JavaScript 代码：

```javascript
function greeting(name) {
  console.log(`Hello, ${name}!`);
  return `Welcome to my blog`;
}

greeting("World");
```

Python 代码示例：

```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))
```
